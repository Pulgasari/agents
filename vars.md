# vars

path aliases. in chat, `$name` means the path below; `$name/x` is a path inside it.
repos are checked out next to each other under `/home/user` (cloud sessions).

```
$agents  = /home/user/agents
$aufbau  = /home/user/aufbau
$bunker  = /home/user/bunker
$domina  = /home/user/domina
$gestalt = /home/user/gestalt
$htx     = /home/user/htx
$js      = /home/user/js-packages
$rat     = /home/user/rat
$site    = /home/user/pulgasari.github.io
$zugriff = /home/user/zugriff
```

a repo that is not in the session cannot be read through its alias: say so instead of guessing.
